# The Stars Don’t Wait logo assets

These SVGs are project-owned logo artwork for **The Stars Don't Wait**, the public name of the game developed in the internal **SolProject** repository.

## Variants

- `the-stars-dont-wait-mark.svg` — color symbol without the wordmark
- `the-stars-dont-wait-lockup-horizontal.svg` — primary wide lockup
- `the-stars-dont-wait-lockup-stacked.svg` — centered display lockup
- `the-stars-dont-wait-lockup-monochrome.svg` — white single-color lockup for dark backgrounds; recolor all `#ffffff` values together when a dark-on-light version is needed
- `../favicon.svg` — simplified small-size application of the symbol

All logo files have transparent backgrounds except the favicon, which includes a dark field for predictable browser-tab contrast. The wordmark uses original SVG paths rather than a third-party font, so its appearance does not depend on locally installed typefaces.

## Source and ownership

The direction was selected by the project owner on 2026-08-16 from AI-assisted visual explorations made specifically for The Stars Don't Wait, then redrawn as deterministic SVG geometry in this repository. It contains no imported third-party artwork, trademarks, fonts, or stock media.

These assets are covered by the repository license unless the project owner publishes separate brand-usage terms later.
