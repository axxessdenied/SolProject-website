# Generated space backgrounds

These decorative backgrounds were generated on August 26, 2026, at the project
owner's request using OpenAI's built-in image generation tool. They are approved
for use on The Stars Don't Wait website under the applicable OpenAI terms. They
are atmospheric concept backgrounds, not screenshots or depictions of shipped
game assets.

The generated PNG sources were converted to quality-82 WebP files with Sharp for
the website. The committed files are 1672 × 941 pixels and each primary route
loads only its assigned image.

## Prompt set

All prompts requested cinematic, realistic, restrained 16:9 space artwork with a
dark left-center copy area, mobile-safe cropping, and no text, logos, watermarks,
UI, characters, or recognizable franchise imagery.

- `home.webp`: a planetary horizon beneath a blue-black starfield, restrained
  amber nebula, and distant sun.
- `game.webp`: a frontier system with a distant jump gate, trade-route trails,
  tiny ship silhouettes, an asteroid belt, and a blue gas giant.
- `engine.webp`: precise orbital arcs, a sparse navigation grid, coordinate
  lights, and a fragmented crystalline moon.
- `roadmap.webp`: a diagonal chain of stellar beacons leading through dark
  interstellar clouds toward a bright horizon.
- `updates.webp`: a distant compact star transmitting concentric signal waves
  through a blue-violet nebula.
